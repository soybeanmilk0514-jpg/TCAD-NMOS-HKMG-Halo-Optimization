# Source Code Scope

The source directory contains code transcribed from the submitted project code PDF.

- `sprocess/`: process construction including HKMG, halo, LDD, spacer, and S/D formation
- `sdevice/`: Id–Vg electrical simulation at two drain biases
- `svisual/`: plotting and metric extraction logic

Line wrapping from the PDF was normalized for readability. The repository does not claim that these files were re-run after transcription.
