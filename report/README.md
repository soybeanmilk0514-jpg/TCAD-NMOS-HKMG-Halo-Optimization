# Source Material

This repository was reconstructed from two project PDFs from the 2026 Semiconductor Integrated Process course:

1. 13-page team presentation: 60 nm NMOS SCE/leakage suppression using HKMG and Halo Doping
2. 9-page code appendix containing SProcess, SDevice, and SVisual scripts

The repository keeps claims limited to values explicitly supported by those files. It does not claim that the transcribed source was re-run after portfolio reconstruction.

Known source inconsistencies are documented in [`guide/08_limitations_and_next_steps.md`](../guide/08_limitations_and_next_steps.md).
