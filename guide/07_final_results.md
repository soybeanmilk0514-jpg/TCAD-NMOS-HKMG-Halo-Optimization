# 07. Final Results

## Selected Structure

`Baseline + HKMG + Halo Doping`

| Parameter | Selected value |
|---|---:|
| Gate length | 60 nm |
| High-k | HfO₂ |
| Halo Dose | `2e13 cm^-2` |
| Halo Energy | `20 keV` |
| Halo Tilt | `25°` |

## Reported Electrical Result

| Metric | Result |
|---|---:|
| Ioff | `1.465e-15 A/µm` |
| Ion/Ioff | `1.41e12` |
| SS | `68–69 mV/dec` |

The report explains the selected condition as combining deeper/angled pocket placement with a moderate dose, thereby improving electrostatic control without using the highest halo concentration.

## Key Engineering Takeaway

The project did not simply add high-k and assume improvement. HKMG-only simulation exposed a punch-through problem, and the process was iterated by adding and tuning junction engineering. This problem → diagnosis → process modification → re-evaluation flow is the central result of the project.
